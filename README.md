# What is CommunitAI?

CommunitAI is an AI-powered Chief of Staff for community leaders — HOA boards, campus clubs, sports committees, and anyone who runs meetings and drowns in the follow-up.

Upload a meeting recording and CommunitAI handles the rest: transcription, action item extraction, sentiment analysis, AI-generated summaries, and one-click follow-up drafts for every task owner. Manage multiple communities from a single dashboard.

> Community leaders spend more time on spreadsheets than on people. CommunitAI fixes that.

**Live demo:** [communit-ai.vercel.app](https://communit-ai.vercel.app) — use the demo account or register free.

## Features

| Feature | Description |
|---|---|
| **Smart Transcription** | Upload MP3, WAV, or M4A — or record live in the browser. Powered by Groq Whisper. |
| **Instant AI Summary** | Clean, structured meeting summary generated by DigitalOcean Gradient AI. |
| **Action Item Extraction** | Every task, owner, and deadline pulled out automatically — zero manual effort. |
| **Sentiment Analysis** | Health score per meeting so you know when morale is dipping before it becomes a problem. |
| **AI Follow-up Drafts** | One click generates a personalised nudge for every task owner. |
| **Multi-workspace** | Switch between your HOA, campus group, and sports club seamlessly. |
| **AI Planner** | Chat with an AI assistant that knows your workspace history and open tasks. |
| **Retry & Resume** | Failed pipeline steps resume from where they left off — no full re-runs. |

## Architecture

```
frontend/   Next.js 15  — App Router · TypeScript · Tailwind CSS v4 · Framer Motion
backend/    FastAPI     — SQLAlchemy (async) · Alembic · PostgreSQL · DigitalOcean Spaces
agent/      Gradient AI — ADK pipeline: Whisper → Extract → Analyze → Summarize
```

The agent pipeline runs sequentially and is fault-tolerant — each step writes its result to the DB and Spaces before the next begins, so a failure at any step can be retried from that point.

## Local Development

### Prerequisites

- Node.js 20+
- Python 3.12+
- PostgreSQL (local or managed)

### 1. Configure environment

```bash
cp backend/.env.example backend/.env
cp agent/.env.example    agent/.env
cp frontend/.env.example frontend/.env.local
```

Edit each `.env` with your credentials — see [Environment Variables](#environment-variables).

### 2. Start services

Run each in a separate terminal from the project root:

```bash
# Backend
backend/.venv/bin/uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# Agent
agent/.venv/bin/uvicorn agent.server:app --host 0.0.0.0 --port 8001 --reload

# Frontend
cd frontend && npm run dev
```

| Service  | URL |
|----------|-----|
| Frontend | http://localhost:3000 |
| Backend  | http://localhost:8000 |
| Agent    | http://localhost:8001 |

### 3. Run migrations

```bash
cd backend && ../.venv/bin/alembic upgrade head
```

### 4. Seed demo data

```bash
cd backend && python seed_demo.py
```

This creates `demo@communitai.app` / `demo1234` with 3 workspaces, 14 meetings, full transcripts, summaries, sentiment reports, and action items.

## Environment Variables

### Backend & Agent

| Variable | Description |
|---|---|
| `DATABASE_URL` | PostgreSQL async connection string (`postgresql+asyncpg://...`) |
| `DO_SPACES_KEY` | DigitalOcean Spaces access key |
| `DO_SPACES_SECRET` | DigitalOcean Spaces secret |
| `DO_SPACES_REGION` | Spaces region (e.g. `nyc3`) |
| `DO_SPACES_BUCKET` | Spaces bucket name |
| `DO_SPACES_ENDPOINT` | Spaces endpoint URL |
| `GRADIENT_API_KEY` | DigitalOcean Gradient AI API key |
| `GRADIENT_MODEL_ACCESS_KEY` | Gradient AI model access key |
| `GRADIENT_INFERENCE_URL` | Gradient AI inference endpoint |
| `GRADIENT_INFERENCE_MODEL` | Model ID to use for inference |
| `GROQ_API_KEY` | Groq API key (Whisper transcription) |
| `AGENT_ENDPOINT_URL` | ADK agent base URL |
| `AGENT_API_KEY` | ADK agent API key |
| `SECRET_KEY` | JWT signing secret |
| `DEMO_EMAIL` | Demo account email (default: `demo@communitai.app`) |
| `DEMO_PASSWORD` | Demo account password |

### Frontend

| Variable | Description |
|---|---|
| `NEXT_PUBLIC_API_URL` | Backend API base URL (e.g. `http://localhost:8000/api`) |

## Deployment

Backend and agent are deployed on **DigitalOcean App Platform** using Dockerfiles. Frontend is deployed on **Vercel**.

Each service has its own `Dockerfile`. The backend copies source into `/app/backend/` and sets `PYTHONPATH=/app` so all `backend.*` imports resolve correctly inside the container.
